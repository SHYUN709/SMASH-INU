# SMASH INU

인천대학교 캠퍼스(송도 + 미추홀)를 3D로 부수는 브라우저 게임입니다. 스트레스 해소용.
부순 만큼 **우리 단과대 점수가 바로 오르는 단과대 대항**이 핵심이에요.
학교와 관계없는 비공식 팬 게임이며, 학교 로고와 교표는 쓰지 않습니다.

바로 하기: https://smash-inu.vercel.app/

## 하는 법

- 도구를 고르고 건물을 누르면 부서집니다. 숫자 키 1~5로도 바꿀 수 있어요.
  - **폭탄**: 누른 곳이 터집니다.
  - **쇳덩이**: 철거용 쇳덩이가 누른 곳을 화면 안쪽 방향으로 쓸고 지나갑니다.
  - **레이저**: 화면을 끌어 선을 그으면 그 선을 따라 건물을 자릅니다.
  - **운석**: 누른 곳에 운석이 떨어져 큰 구덩이를 만듭니다.
  - **지진**: 누른 곳을 중심으로 3초 동안 흔들립니다. 높은 층부터 떨어집니다.
- 받침이 빠진 블록은 위층까지 무너지고, 건물이 40% 가까이 부서지면 통째로 붕괴합니다.
- 빠르게 계속 부수면 랭크가 D → C → B → A → S → SS → SSS로 올라가고 점수 배율이 붙어요. 도구를 섞어 쓰면 배율이 더 오르고, 한 도구만 쓰면 깎입니다.
- 조작: 끌기는 돌리기, 오른쪽 끌기(또는 Shift+끌기)는 옮기기, 휠은 확대. 휴대폰은 두 손가락으로 확대, 회전, 이동.
- 많이 부서진 건물(통째로 무너졌거나 65% 넘게 부서진 건물)은 4초 뒤 저절로 다시 지어져요. 부술 거리가 떨어지지 않습니다.
- **다시 짓기**(R 키)로 캠퍼스 전체를 처음 모양으로 되돌립니다. 점수는 그대로예요.

## 단과대 대항 (오늘 누적)

- 처음 들어오면 **랭킹 참가 설정**을 한 번 받아요: 익명 / 닉네임 / 참가 안 함, 그리고 소속 단과대(필수). 점수판 아래 단과대 배지나 랭킹의 **내 정보**로 언제든 바꿀 수 있어요.
- 따로 판이 없어요. 부수는 동안 번 점수가 **오늘 내 점수**에 쌓이고, 30초쯤마다 묶어서 우리 단과대 점수에 더해집니다. 탭을 닫거나 다른 앱으로 넘어갈 때도 남은 점수를 보내요. 못 보낸 점수는 버리지 않고 다음에 같이 보냅니다.
- 도구판 바로 위 한 줄에 **단과대 1~3위, 우리 단과대 순위, 바로 윗 순위까지 남은 점수**가 보여요. 누르면 전체 순위와 오늘 내 점수가 펼쳐집니다. 펼친 채로 계속 부술 수 있어요.
- 우리 단과대 순위가 오르면 화면에 알려 줘요 (예: "정보기술대 3위 → 2위!").
- 단과대 대항은 매일 자정(한국 시간)에 새로 시작해요. 다른 사람에게는 단과대별 합계와 참가 인원만 보여요.
- 참가 안 함을 고르면 점수를 보내지 않고 혼자 즐깁니다.

### 닉네임이 보이는 곳

- **개인 랭킹:** 펼친 랭킹의 **개인 랭킹** 탭에 오늘 누적 점수 TOP 20이 나와요. 순위, 닉네임, 단과대, 점수가 보이고, **닉네임으로 참가한 사람만** 올라가요. 익명 참가자의 점수는 단과대 대항에만 들어갑니다. TOP 20 밖이면 아래에 "내 순위 47위"처럼 따로 보여 줘요. 자정에 단과대 대항과 같이 새로 시작해요.
- **단과대 기여 TOP 5:** 단과대 대항 탭에서 단과대를 누르면 그 단과대에 오늘 가장 많이 기여한 5명이 펼쳐져요. 익명 참가자는 "익명"으로 보여요.
- **순위 상승 알림:** 내가 보낸 점수로 우리 단과대 순위가 오르면 "성현님 덕분에 정보기술대 2위 → 1위!"처럼 알려 줘요. 나한테만 보여요.
- **내 기여도:** 점수판 아래 배지(예: "정보대 2위 · 4.2%")와 펼친 랭킹 아래에 "정보기술대에 오늘 3,240점 기여 (4.2%)"가 나한테만 보여요.
- 하루 중에 닉네임을 바꾸면 오늘 점수도 새 닉네임으로 보이고, 익명으로 바꾸면 개인 랭킹에서 빠져요.
- 욕설이 들어간 닉네임은 저장할 수 없어요. 서버에서도 한 번 더 걸러서, 걸린 닉네임은 어디에도 보이지 않아요.

### 랭킹 서버 켜기 (Supabase, 무료)

1. [supabase.com](https://supabase.com)에서 프로젝트를 하나 만듭니다.
2. **SQL Editor**에 `supabase/schema.sql`을 통째로 붙여 넣고 실행합니다.
3. **Project Settings → API**에서 Project URL과 공개 키(anon 또는 publishable)를 복사해 `config.json`에 넣습니다.
   ```json
   { "supabaseUrl": "https://xxxx.supabase.co", "supabaseKey": "공개 키" }
   ```
   공개 키는 브라우저에 보여도 되는 키예요. **service_role(secret) 키는 절대 넣지 마세요.**
4. push하면 끝. `config.json`이 비어 있으면 랭킹 없이 혼자 부수기만 됩니다.

서버 구조와 방어:
- 점수는 "하루 × 기기" 한 줄에 더하고(`inu_scores`), 동시에 "오늘 × 단과대" 합계 표(`inu_college_day`, 최대 13줄)에도 바로 더해요. 순위 조회는 이 13줄만 읽어서 사람이 몰려도 가볍습니다.
- 기기 구분은 브라우저에 저장한 랜덤 id예요. **기기당 1분 6번**까지 받는 게 주된 방어이고, 같은 공인 IP는 학교 와이파이를 생각해 **1분 600번**까지로 아주 느슨하게 둡니다.
- **시간 기준 점수 상한:** 기기마다 초당 5만 점씩 차는 "점수 통"이 있고(최대 150만 점, 한 번 요청은 300만 점까지), 서버는 통에 든 만큼만 받아요. 넘는 몫은 버리지 않고 게임이 다음 전송에 다시 보내요. 그래서 몇 초 간격으로 보내든 같은 시간에 받을 수 있는 점수는 같아요. 그 밖에 단과대 필수, 닉네임 10자, 닉네임 욕설 검사.
- 브라우저는 함수(`inu_add`, `inu_board`, `inu_people`, `inu_college_top`, `inu_set_nick`)만 부를 수 있고, 표는 직접 읽거나 쓸 수 없어요. 개인 랭킹 응답에도 기기 id는 들어가지 않아요.
- `schema.sql` 맨 아래 주석에 관리용 SQL이 있어요. 이상한 점수를 지우고 단과대 합계를 다시 계산하는 SQL, 특정 기기나 닉네임을 개인 랭킹과 기여 TOP 5에서 숨기는 SQL이에요. SQL Editor에서만 실행됩니다.
- `schema.sql`은 다시 실행해도 기록이 지워지지 않아요. 업데이트할 때는 맨 아래 **"이번 업데이트용 SQL"** 구역만 실행해도 돼요. 기존 함수의 이름, 인자, 반환 형태는 그대로 두고 키만 더하기 때문에, 옛날 버전으로 켜 둔 게임도 계속 동작합니다.

단과대 목록은 `index.html`의 `COLLEGES`와 `schema.sql`의 코드 목록을 함께 고치면 됩니다.

### 랭킹 서버가 멈췄을 때 (Supabase 무료 프로젝트 일시정지)

무료 프로젝트는 한동안(대략 1주일) 요청이 없으면 **자동으로 일시정지**돼요. 그러면 게임은 되지만 랭킹 바에 "랭킹 불러오는 중"만 보입니다.

1. [supabase.com/dashboard](https://supabase.com/dashboard)에 로그인해 `SMASH-INU` 프로젝트를 엽니다.
2. "Project is paused" 화면에서 **Restore project**(또는 Resume)를 누릅니다.
3. 몇 분 뒤 상태가 **Healthy**가 되면 끝. 기록과 설정은 그대로 남아 있어요. 게임 쪽은 고칠 것이 없습니다.

오래 멈춰 있으면 복구 버튼이 사라질 수 있으니, 시험기간처럼 쓸 때가 다가오면 미리 한 번 열어 보세요.

## 진짜 인천대 데이터 넣기

`data/campus.json`이 없으면 연습용 가짜 캠퍼스가 나옵니다. 한 번만 실행하면 됩니다.

```bash
python tools/fetch_campus.py
```

(맥은 `python3`) OpenStreetMap에서 **송도캠퍼스**와 사범대학이 있는 **미추홀캠퍼스**를 둘 다 찾아 건물과 길을 받고, `data/campus.json` 하나로 저장합니다. 추가 라이브러리는 필요 없어요.

- 미추홀캠퍼스는 실제로는 2km 넘게 떨어져 있지만, 게임 지도에서는 송도캠퍼스 바로 동쪽에 붙여 놓습니다. 화면 왼쪽 위 **전체 / 송도 / 미추홀** 버튼으로 카메라를 옮길 수 있어요.
- 미추홀캠퍼스가 OSM에 캠퍼스 영역으로 그려져 있지 않으면 건물 이름(미추홀타워 등)이나 주소(갯벌로 12)로 찾아서 주변 140m 건물을 받습니다. 학교 건물이 아닌 게 섞이면 `campus.json`에서 그 건물을 지우세요.

자동으로 못 찾을 때는 [openstreetmap.org](https://www.openstreetmap.org)에서 캠퍼스(또는 건물)를 클릭해 ID를 확인한 뒤 직접 넣으세요.

```bash
python tools/fetch_campus.py --songdo way 123456789
python tools/fetch_campus.py --michuhol way 987654321
python tools/fetch_campus.py --michuhol-at 37.3820 126.6560   # 위도 경도로 지정
python tools/fetch_campus.py --no-michuhol                      # 송도캠퍼스만
```

`Overpass ... 실패, 다른 서버로 다시 시도합니다`는 서버가 붐빌 때 나오는 정상 메시지예요. 그대로 기다리면 다른 서버로 넘어갑니다.

층수 정보가 없는 건물은 5층으로 어림합니다. 높이가 이상한 건물은 `campus.json`에서 그 건물의 `h`(미터)를 고치면 됩니다.

## 내 컴퓨터에서 해 보기

`index.html`을 더블클릭하면 데이터 파일을 못 읽습니다. 프로젝트 폴더에서 간단한 서버를 켜세요 (윈도우 cmd 기준, 맥은 `python3`).

```bash
python -m http.server 8000
```

그리고 브라우저에서 http://localhost:8000 을 엽니다.

**폰으로 확인하기:** PC와 폰을 같은 와이파이에 연결하고, cmd에서 `ipconfig`로 PC의 IPv4 주소(예: `192.168.0.12`)를 확인한 뒤 폰 브라우저에서 `http://192.168.0.12:8000` 을 엽니다. 안 열리면 윈도우 방화벽에서 Python의 "개인 네트워크" 접근을 허용하세요. 이때 `config.json`이 채워져 있으면 실제 랭킹 서버에 점수가 올라가니, 테스트 점수는 관리용 SQL로 지우면 됩니다.

## GitHub Pages로 올리기

1. GitHub에 `SMASH-INU` 저장소를 만들고 이 폴더를 올립니다 (`data/campus.json` 포함).
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 고릅니다.
3. 1~2분 뒤 `https://<아이디>.github.io/SMASH-INU/`에서 열립니다.

## 만든 방법

- 3D는 three.js r160 (CDN), 소리는 Web Audio로 합성합니다. 소리 파일은 없습니다.
- 건물 바닥 모양을 격자로 잘라 층마다 블록을 쌓고, 블록 전체를 `InstancedMesh` 하나로 그립니다. 블록 수는 컴퓨터 약 4만 개, 휴대폰 약 2만 개로 맞춰 블록 크기를 자동으로 정합니다.
- 송도는 매립지라 땅이 평평해서 고도 데이터는 쓰지 않습니다.
